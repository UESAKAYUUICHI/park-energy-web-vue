# 公共样式约定

- `index.css`：唯一入口，页面和组件不要重复导入样式文件。
- `tokens.css`：颜色、字体、圆角等设计变量。
- `reset.css`：浏览器基础重置与应用根节点尺寸。
- `forms.css`：表单分区、详情网格、检查项。
- `workbenches.css`：企业工作台、左侧队列、工具栏、状态摘要。
- `media.css`：统一图片加载、空态、失败和重试状态。
- `utilities.css`：少量稳定布局工具类。
- `assets/main.css`：现有全局组件与历史业务样式，后续新增通用模式应进入上述分层文件。

页面专属视觉允许保留 `scoped`；两个及以上页面重复出现的规则必须提升到这里。
